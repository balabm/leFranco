# Le Franco.in - Official Website

A modern, responsive website for Le Franco.in, a premier cultural and cinematic platform based in Pondicherry, celebrating the transformative power of film and media through prestigious awards and festivals.

## 🎬 About Le Franco.in

Le Franco.in is dedicated to recognizing, honoring, and promoting creative excellence through:
- **Annual Film Awards** - Celebrating the year's most impactful films and directors
- **Media Awards Festival** - Recognizing excellence in journalism and digital media  
- **International Film Carnivals** - Fostering global cultural exchange and collaboration

## ✨ Website Features

- **Modern Design** - Clean, professional interface with premium aesthetics
- **Fully Responsive** - Perfect display across all devices and screen sizes
- **Smooth Animations** - Engaging transitions and interactive elements
- **Accessible** - Built with accessibility best practices
- **Performance Optimized** - Fast loading times and smooth navigation
- **SEO Ready** - Optimized for search engines

## 🚀 Technology Stack

- **React 18** - Modern component-based UI framework
- **TypeScript** - Type-safe development
- **Vite** - Fast build tool and development server
- **Modern CSS** - Custom properties, Grid, Flexbox
- **Responsive Design** - Mobile-first approach

## 🛠️ Development

### Prerequisites
- Node.js (version 16 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) to view the website.

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
